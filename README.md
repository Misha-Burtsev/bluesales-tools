# BlueSales – новый мессенджер

Стили и помощник для мессенджера BlueSales (https://bluesales.ru/app/Messenger/).

## Установка

1. Поставить расширения в Chrome: [Tampermonkey](https://chromewebstore.google.com/detail/dhdgffkkebhmkfjojejmpbldmpobfkfo) и [Stylus](https://chromewebstore.google.com/detail/clngdbkpkpeebahjckkjfobafhncgmne).
2. Для Tampermonkey включить «Режим разработчика» в chrome://extensions (иначе скрипты не запускаются).
3. Открыть по очереди ссылки и нажать «Установить»:
   - [Помощник (Tampermonkey)](https://raw.githubusercontent.com/Misha-Burtsev/bluesales-tools/main/bluesales-helper.user.js)
   - [Новый мессенджер (Stylus)](https://raw.githubusercontent.com/Misha-Burtsev/bluesales-tools/main/bluesales-messenger.user.css)
   - [Тёмная тема (Stylus), по желанию](https://raw.githubusercontent.com/Misha-Burtsev/bluesales-tools/main/bluesales-messenger-dark.user.css)

Обновления приходят сами: Tampermonkey и Stylus периодически проверяют новую версию.
Обновить сразу: в расширении – «Проверить обновления».

## Что умеет помощник

- звуки входящих и отправки, отключаются отдельно;
- избранные смайлики и поиск по ним;
- переключатель светлой и тёмной темы;
- таймер «клиент ждёт», напоминания и закреплённые чаты;
- черновики по чатам, поиск по быстрым фразам;
- счётчик ссылок и отчёт за смену с подсчётом лидов, блоков и чатов в работе.
